- **Production diagnostic exposure:** `WP_DEBUG_DISPLAY` is enabled while `WP_DEBUG` is disabled. Keep error display disabled in production to prevent accidental disclosure if debugging is later enabled; use protected logs instead.
- **Database character-set alignment:** The database reports `utf8mb4`, but `DB_CHARSET` is set to `utf8`. Confirm the WordPress configuration and database schema are intentionally aligned before changing either setting; `utf8mb4` is generally preferred for complete Unicode support.
- **Storage management:** The installation is 16.57 GB, with uploads accounting for 4.16 GB. Establish retention, backup, and media-optimisation routines, and review large files periodically.
