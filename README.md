# Haraka

Haraka is a corporate content hub plugin for WordPress that manages Events, Tenders, and Careers with structured listings and elegant single-page templates.

Built for enterprise and institutional websites, originally developed for IIUM Holdings.

---

## Features

- Event management system
- Tender listing management
- Career posting management
- Structured custom post types
- Elegant single-page templates
- Enterprise-ready architecture
- WordPress-native integration

---

## Installation

1. Download the plugin ZIP
2. Upload to WordPress via Plugins → Add New
3. Activate the plugin
4. Configure settings if applicable

---

## Requirements

- WordPress 6.0+
- PHP 8.0+
